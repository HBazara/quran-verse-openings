# User guide | دليل الاستخدام

## English

The site is not built yet. This guide will explain how to use it once the reader is ready (phase 3 onward).

What the site will do: it shows the Quran page by page like a printed mushaf, but each verse shows only its first words. The words sit in the same place as on the printed page. Read the opening, then recite the rest of the verse from memory.

## العربية

الموقع لم يُبنَ بعد. سيشرح هذا الدليل طريقة استخدامه عندما يصبح القارئ جاهزًا (من المرحلة الثالثة فصاعدًا).

ما سيقدمه الموقع: يعرض القرآن صفحةً صفحة مثل المصحف المطبوع، لكن كل آية تظهر منها كلماتها الأولى فقط، في المكان نفسه الذي تقع فيه على الصفحة المطبوعة. اقرأ بداية الآية، ثم أكمل باقيها من حفظك.
